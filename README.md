# vRP Radar

> Early Project / Legacy Repository

## Features

- Multiple radar locations
- Vehicle speed detection
- Progressive fines based on speed
- Police and paramedic exemptions
- Visual/audio feedback when crossing a radar

## Tech Stack

- Lua
- FiveM
- vRP
